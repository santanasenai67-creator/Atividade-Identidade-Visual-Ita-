# 🎨 Trabalho de Design System — Itaú

## 📌 Sobre o projeto

Este projeto consiste na criação de um **Design System inspirado na identidade visual do Itaú**, desenvolvido no Figma.

O objetivo é organizar e padronizar os principais elementos visuais utilizados em uma interface, garantindo maior consistência, acessibilidade e facilidade durante o desenvolvimento de telas e aplicações.

## 🎯 Objetivo

Criar uma base visual contendo:

- Paleta de cores;
- Tipografia;
- Escala de fontes;
- Exemplos de contraste;
- Hierarquia visual;
- Padrões que podem ser reutilizados em diferentes interfaces.

## 🔤 Tipografia

A fonte utilizada no projeto é a **Poppins**, escolhida por sua aparência moderna e facilidade de leitura.

### Escala tipográfica

| Elemento | Tamanho |
|---|---:|
| Small | 14px |
| Parágrafo | 16px |
| H5 | 18px |
| H4 | 24px |
| H3 | 28px |
| H2 | 34px |
| H1 | 40px |

Foram utilizados diferentes pesos da fonte para criar uma boa hierarquia entre títulos, subtítulos e textos.

## ♿ Contraste

O projeto também apresenta exemplos de contraste entre diferentes cores e tamanhos de texto.

Essa etapa é importante para garantir que as informações tenham **boa legibilidade e acessibilidade**, principalmente quando utilizadas em interfaces digitais.

Foram apresentados exemplos utilizando:

- Fundo claro;
- Fundo laranja;
- Fundo escuro;
- Textos em diferentes tamanhos e pesos.

O projeto está organizado em uma única página contendo:

4. Escala de fontes;

## 👨‍💻 Desenvolvimento

Este trabalho foi desenvolvido com o objetivo de aplicar conceitos de **UI/UX Design, Design System, tipografia, cores e acessibilidade** na criação de uma identidade visual organizada e reutilizável.
